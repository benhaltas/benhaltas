# Ahmed Haltas

Mechanical Engineer and M.Eng. Industry 4.0 student based in Baden-Württemberg, Germany, focused on PLC/SPS programming, industrial automation, control engineering, and commissioning. This portfolio is platform-neutral: the projects provide hands-on Beckhoff TwinCAT 3 evidence, while Siemens TIA Portal is part of my current development focus.

## Focus

- PLC/SPS programming and IEC 61131-3 Structured Text
- Industrial automation, control engineering, and commissioning
- Siemens TIA Portal and Beckhoff TwinCAT 3
- HMI, EtherCAT, motion control, and PLCopen function blocks
- OPC UA, digital twins, and virtual commissioning

## Selected Automation Projects

### 1. [Beckhoff TwinCAT 3 - Linear Axis Control](https://github.com/benhaltas/Beckhoff-TwinCAT3-Linear-Axis-Control)

Single-axis control project using Structured Text and PLCopen motion blocks. It includes manual and automatic sequences, end-sensor and travel-limit handling, EtherCAT axis configuration, and TwinCAT HMI monitoring.

### 2. [Festo Digital Twin - TwinCAT 3 and OPC UA](https://github.com/benhaltas/Festo-Digital-Twin-TwinCAT3-OPC-UA)

Digital-twin project connecting a Siemens NX Mechatronics Concept Designer model to TwinCAT 3 through OPC UA. The project used a time-based, open-loop virtual test sequence and does not claim full physical commissioning of the Festo system; the public case study does not publish the sequence source.

### 3. [Beckhoff TwinCAT 3 - Smart Factory HMI](https://github.com/benhaltas/Beckhoff-TwinCAT3-Smart-Factory-HMI)

Process-control project with a CASE-based state machine, TwinCAT HMI, structured recipe handling, simulated production and maintenance values, and ADS/Python process monitoring.

### 4. [Beckhoff PLC Programming Learning Path](https://github.com/benhaltas/Beckhoff-PLC-Programming-Learning-Path)

Thirteen hands-on projects progressing from PLC fundamentals to HMI, EtherCAT, state machines, object-oriented PLC programming, PLCopen motion control, and TwinSAFE safety-logic concepts.

Additional Unity projects cover [industrial robot pick-and-place simulation](https://github.com/benhaltas/Unity3D-Industrial-Robot-PickAndPlace) and a [3D endless-runner game](https://github.com/benhaltas/Unity3D-Run-Mouse-Endless-Runner).
